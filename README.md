# ATU Student Study Planner

A simple web app that helps students organise their study tasks and assignments. Built as the final individual mini project for the ATU Virtual Internship in Web Development and Software Development (MASTACLAZ COMPANY LTD, October 2026).

**Live demo:** https://sammy-hub-max.github.io/ATU-student-study-planner/

## Features
- Add a study task with a title (required) and a subject or course
- View all saved tasks in a list
- Mark tasks as completed, or change them back to incomplete
- Delete tasks you no longer need
- Tasks are saved in the browser's local storage, so they stay after a page refresh

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code (editor)
- GitHub and GitHub Pages (hosting)

## Project Structure
- `index.html`: page structure
- `style.css`: styling
- `script.js`: task logic and local storage

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation is needed.
